# 原型转化协议 · Archetype Conversion Protocol

> **适用范围**：模式 C（历史人物转现代议会制原型），以及近现代现实人物被拒后的“提炼 → 转化”安全兜底。
>
> **核心理念**：原型转化不是简单总结政治思想，而是**提炼“一个人的结构”**——保留人格结构与行为模式的味道，删除可识别的具体事实指纹。

> **历史语境转译原则**：不要直接使用历史人物在原时代中的具体立场。先剥离时代环境，提炼稳定人格结构，再放入现代议会制语境推演其最可能的现代立场。

---

## 1. 转化目标

把一个历史人物 / 被拒的现实人物，转成一个**不可识别的现代议会制虚构政治家**，同时：

- 保留：人格底色、欲望结构、弱点、行为模式、政治气质、领导风格、说话节奏、情绪触发点……
- 删除：具体历史事件、战争、政变、丑闻、死亡方式、亲属关系、家臣部下、政策口号、唯一性指纹……（真实政党名称允许保留，见 §3 修订）

> 转化的产物必须是**有血有肉的政治人物**，不是一份干瘪的标签清单。

---

## 2. 可保留内容（从原型中提炼）

从历史人物或政治类型中，可以保留：

- 人格底色
- 欲望结构
- 弱点
- 行为模式
- 政治气质
- 领导风格
- 用人方式
- 对敌方式
- 对盟友方式
- 危机反应
- 组织观
- 权力观
- 自我叙事
- 公开形象
- 私下恐惧类型
- 生活质感
- 兴趣审美
- 说话节奏
- 情绪触发点

这些是“结构”，不是“事实”，因此不会把角色重新绑定到某个现实个体。

### 2.1 先提炼人格，再推演立场

Mode C 的核心不是“把古代政治主张翻译成现代政策”，而是先找出这个人之所以仍然是这个人的本质识别条件。

稳定人格结构包括：

- 气质：行动速度、耐心、情绪强度、控制欲、开放性、风险承受；
- 欲望：想证明什么、想打破什么、想守住什么；
- 恐惧：最怕哪种失败、背叛、失控、停滞或被时代抛弃；
- 弱点：冲动、多疑、傲慢、过度信任、过度控制、过度依赖威望等；
- 人际模式：如何信任、如何对待自己人、如何对待敌人；
- 组织观：相信能力、血统、制度、魅力、秩序、群众授权，还是资源控制；
- 权力观：权力是用来维持秩序、打破壁垒、实现使命，还是绑定追随者；
- 危机反应：先发制人、稳住中枢、动员群众、谈判妥协、牺牲局部等。

然后才进入现代立场推演：

1. 在历史时代中识别他实际面对的主要矛盾；
2. 删除不可迁移的历史结构；
3. 在现代议会制中分析其面对的社会情况、制度条件与政治约束；
4. 让稳定人格结构对这些现代条件作出反应；
5. 再填写 `ideology` 六轴、支持基础、行动方式与权力计算。

**说人话——为什么这样转化**：一层是从跨情境反复行为中推断的相对稳定倾向（脾气、欲望、恐惧、反应方式），另一层是被出身、经历和制度环境训练出的局势判断。历史立场是两者与当时社会共同作用的结果；社会变了，立场必须重算。这里不推断遗传来源，也不声称先天注定。

### 2.1.1 历史手段 ≠ 人格（最常见的错误，禁止用手段反推）

历史人物的具体政策、制度选择、政治手段（如乐市乐座、屯田、挟天子以令诸侯、populares 路线、老兵分地）是**特定生产力与社会条件下的产物，不是人格本身**。

**为什么手段不能反推立场**：一个人在那个时代能做什么、只能做什么，受当时的生产力和社会条件卡着。比如封建时代的生产力根本不允许真正“反封建”，所以人物在旧约束下用的那些手段（乐市乐座、屯田……），只是他的性格底子在当时能找到的有限表达；换到生产力完全不同的现代社会，这些具体手段没有迁移意义。要留的是性格底子（他为什么要那么做），不是手段本身。

**因此：绝不能用人物在原时代的具体手段反推他现代的立场。** 例如不能因为信长搞过乐市乐座（自由贸易），就推他现代是“市场开放派 / 反垄断改良派”——那是把手段当人格。必须先剥离所有具体手段，提炼手段背后**稳定的、跨时代的人格结构**（他为什么在那个处境下选择那种手段：他要打破什么、他如何看待流通与权力、他的彻底性从何而来），再让这个人格在现代条件下重新生成立场。

### 2.1.2 切入点由人格决定（禁止预设所有人物都抓“社会矛盾”）

转化后的现代立场，由人物的稳定人格结构决定他**如何看现代社会、看到什么问题**——而不是预设他一定抓“社会矛盾”或“阶级矛盾”。不同人格看到不同的现代病，切入点根本不同：

- **革命者人格**（如信长：对垄断/流通敏感、与民众打成一片、理想主义先行）→ 直指**阶级剥削**等根本社会矛盾，倾向颠覆性立场；
- **秩序重建者人格**（如曹操：现实主义、控制欲、治理型理想）→ 看到**治理失序、国家能力瓦解**，出发点是收拾局面而非抓矛盾；
- **使命驱动的强人**（如凯撒：自我神圣化、魅力型、制度边界感弱）→ 看到**成就历史伟业的机会**（僵化精英挡路），出发点是成大事而非解矛盾。

**必须先问“这个人的人格会从什么角度看现代”，再推演他抓住什么矛盾、推出什么立场。** 绝不能套用同一个矛盾模板（尤其不能默认所有激进人物都指向阶级矛盾 / 反资本主义）——那等于把信长的答案复制给所有人，是新的脸谱化。三人同样强势，但对“制度”的态度却不同（信长重塑、曹操维护、凯撒突破），切入点也互不相同。

### 2.2 禁止历史立场直译与两种常见误推

错误做法：

- 织田信长反封建 → 现代仍写成“反封建”；
- 曹操重建秩序 → 现代直接写成保守派；
- 凯撒动员平民 → 现代直接写成民粹；
- 古代强势君主 → 现代直接写成国家主义右翼；
- 古代开放贸易 → 现代直接写成自由市场右派；
- **用历史手段反推现代立场**：因信长搞过乐市乐座（自由贸易）就推他现代是“市场开放派 / 反垄断改良派”（见 2.1.1）；
- **预设所有激进人物都抓阶级矛盾 / 反资本主义**：把信长的答案套给曹操、凯撒（见 2.1.2）；
- **把后世政治评价标签当作人格本身**：因主流史学称信长为“革命者 / 革新者”，就在 `personality_archetype` 中写“信长是一名青年革命者”（见 2.3）。

正确做法（先剥离手段，再提炼人格，再据人格决定的切入点推演）：

- **织田信长**：先剥离乐市乐座 / 自由贸易这些 16 世纪商品经济萌芽期的特定手段，提炼其稳定人格——理想主义先行（天下布武的新秩序蓝图）、直指根本矛盾的洞察、彻底斩草除根的革命性、对流通垄断的敏感与亲民众；再放入现代阶级矛盾，推演出**最终目标超越资本主义、现阶段依靠合法政治手段的急进左翼改革派**（他判断当今社会条件尚不允许立刻超越资本主义——务实破局的决策人格使然——故不寻求立刻革命、借用议会平台）。注意：信长抓阶级矛盾、以超越资本主义为最终目标，是"对垄断敏感 + 亲民众 + 流通洞察"这一**特定人格**的产物，不是默认值。
- **曹操**：剥离屯田 / 挟天子 / 唯才是举令等手段，提炼“现实主义秩序重建者 + 安邦定国的治理型理想 + 控制型多疑”；他的切入点是**治理失序 / 国家能力瓦解**（非社会矛盾），推演出**现实主义强国家能力的秩序型政治家**（对资本是收服以恢复秩序，非阶级解放）。
- **凯撒**：剥离 populares / 老兵分地等手段，提炼“使命感驱动的魅力强人 + 自我神圣化 + 制度边界感弱”；他的切入点是**成就伟业的机会**（僵化精英挡路，非社会矛盾），推演出**使命感魅力型强人改革领袖**（再分配是借民意成就伟业的杠杆，非阶级解放；会架空制度制衡）。

> 同样强势的三人，对"制度"的态度却不同——信长重塑（institution −38）、曹操维护（+75）、凯撒突破（−65），切入点也互不相同。这正是"切入点由人格决定"的活例证。

### 2.3 禁止后世政治评价标签脸谱化

> ⚠️ 本节是转化阶段的硬规则，与 §2.1.1 / §2.1.2 / §2.2 并列。它在人格提炼阶段的具体落地见 `core/inferred_temperament_extraction.md`「核心原则补充：历史评价 ≠ 人格特征」。

历史人物转化中最隐蔽的脸谱化陷阱：把**后世的政治评价**当作此人的人格本身。

后世史学、教科书、大众文化习惯给历史人物贴政治标签——“革命者”、“革新者”、“保守派”、“反动派”、“民粹”——这些是**后人对结果的评价**，不是此人**行动时的人格结构**。把它们直接写入人格字段，等于用结果反推动机，必然脸谱化。

**禁止做法**（在 `personality_archetype` / `human_core` / `extracted_human_pattern` / `self_states` 等人格字段中）：

- ❌ 直接使用「革新者」「革命者」「保守派」「进步派」「反动派」「改良派」「激进派」等后世政治评价标签定义人物；
- ❌ 把历史结果（推动改革、建立新制度、统一乱世）误认为人格动机；
- ❌ 因大众文化印象（如“魔王信长”、“枭雄曹操”、“凯撒式独裁”）弱化人物复杂性；
- ❌ 用现代政治概念（左/右、自由/保守、革命/反动）强行解释古代人物。

**正确做法**：把“革新性 / 保守性 / 革命性”等历史评价，**翻译为可观察的行为倾向、认知模式、价值排序**：

| ❌ 标签化人格描述 | ✅ 行为倾向描述 |
|---|---|
| “信长是一名革新者” | “信长对无法适应时代变化的旧有秩序具有较低容忍度，倾向根据现实需求重新构建政治和经济结构。他关注社会资源流动与整体秩序重组，但同时高度依赖个人判断，对复杂人际关系中的非理性因素估计不足。” |
| “曹操是保守派” | “曹操倾向维护已能运转的秩序，认为稳定本身具有价值；但若既有制度无法解决现实问题，他也会重新设计。用人重才但用人盯人，敢用不敢信。” |
| “凯撒是民粹领袖” | “凯撒倾向通过个人魅力与大众直接授权推动目标，对制度性协商的低效极度不耐烦；他把自己的追求升华为国家命运，自觉在书写历史。” |

**四条区分原则（生成时的硬规则）**：

- **历史评价 ≠ 人格特征**
- **政治立场 ≠ 性格**
- **历史影响 ≠ 主观动机**
- **成功结果 ≠ 原始意图**

人格生成应回答：“这个人为什么会这样行动？”
而不是：“后人如何评价他的行动？”

**历史评价的合法位置**：可保留在 `historical_source_report.md` 的「主流史学解释 / 争议点」一节，但**必须明确标注为后人评价**（如“被主流史学评为…”、“传统叙事将其塑造为…”、“修正派研究认为…”），不可作为 `personality_archetype`、`temperament`、`core_desires`、`self_states` 等人格字段的描述语。

**注意——不否定历史评价本身**：信长“具有革新性”、曹操“重建秩序”、凯撒“魅力型改革”这些历史评价**仍然成立**，本节不否定它们。本节要求的是：把它们从**人格标签**转换为**行为倾向与认知模式描述**。“具有革新性”作为后人评价没问题；写成“他的性格就是革新者”就是脸谱化。

### 2.3.1 替代标签应提取的四类结构

转化时优先提取以下四类**行为 / 认知 / 价值结构**（这些是可观察、可跨情境一致、可由史料证据支持的，与“革新者/保守派”等事后标签不同）：

- **A. 性格结构**：对规则的态度；对风险的接受程度；决策方式；人际关系模式；情绪特点；优势与弱点。
- **B. 认知模式**：如何理解时代变化；如何判断问题；如何看待传统与现实的关系；如何选择行动方案。
- **C. 行动倾向**：倾向维护已有秩序 / 倾向重构无法适应现实的制度 / 倾向集中资源解决问题 / 倾向通过协商还是强制推动目标。
- **D. 价值排序**：稳定 vs 变化；效率 vs 共识；传统合法性 vs 实际效果；集中决策 vs 分散参与。

这些结构对应 `inferred_temperamental_pattern` 的 18 个推断维度（见 `core/inferred_temperament_extraction.md`），并且是跨时代稳定、可由史料证据支持的人格底子——而不是事后贴上的政治评价。

### 2.4 成长经历 × 性格 → 现代立场（formative life history coherence rule）

> ⚠️ 本节是转化阶段的硬规则。人格底子（temperament / 欲望 / 恐惧 / 反应方式）跨时代稳定，但它**自身不直接产生现代立场**——立场永远是"人格底子 × 现代社会情况 × 个人成长经历"三者的产物。光有人格底子和抽象的现代社会矛盾不够，必须为转化后的现代虚构政治家**构造一段具体的、能与人格底子共同解释其当前立场的现代成长经历**。

**为什么需要成长经历**：

同一个人格底子（如信长的"对权威质疑、判定过时即果断打破"），放进同一个现代社会（发达资本主义 + 议会制），**可以因为成长经历不同而形成完全不同的现代立场**：

- 出身工人阶级、少年目睹亲人被资本压垮 → 反资本主义革命派
- 出身小资产阶级、考入顶尖大学、接触经济学理论后判断"改良行不通" → 反资本主义但带阶级背叛色彩
- 出身资本家家族、亲历家族企业被跨国资本吞并 → 民族资本立场 / 反跨国资本民粹
- 出身农村、目睹农业被金融化挤压 → 农本主义 / 反金融资本

**这些都是同一人格底子的合法现代化**。转化时必须**选择或构造**其中一条 coherent 路径，并说明"这是多种可能解中的一个，非唯一解"。

**强制规则**：

1. 每个转化后的现代 persona 必须有 `formative_life_history` 块，至少含：
   - `class_origin`：出身阶层 / 家庭背景
   - `youth_observations`：少年时期的关键观察 / 经历（通常是 2-3 个具体场景）
   - `intellectual_formation`：思想成型路径（教育、关键阅读、关键人物接触等）
   - `stance_formation_logic`：立场形成的内在逻辑——必须能解释"为什么这个人格 + 这段经历 = 这个立场"
   - `class_relation`：与出身阶级的关系（延续 / 背叛 / 矛盾）
   - `alternative_paths_note`：明确说明这是多种 coherent 解中的一个，并列出 1-2 个其他可能解

2. **盲测式自洽性测试**（必跑，避免循环论证）：把 `personality_archetype` + `formative_life_history` 中**除 `stance_formation_logic` 之外的部分**（即 class_origin / youth_observations / intellectual_formation）交给一个不知来源的读者/AI，问他"这样的人最可能形成什么政治立场？"——如果回答与 `political_core.ideology` 大方向基本一致（不必完全相同），则通过；如果差距大（如预期激进左翼、回答倾向右翼民粹），则不通过。**注意：必须隐去 `stance_formation_logic` 字段，否则等于把答案给了审查者，测试变成自证。**

3. **不要求"出身阶级 = 立场"的简单对应**。恰恰相反，**阶级背叛**（如小资出身 → 反资本主义、资本家出身 → 工运领袖）常常是最有趣的现代化，**只要逻辑自洽即可**。人格底子决定他如何解读成长经历，成长经历决定他看到什么问题——两者合成才产生立场。

4. **不否定"多种 coherent 解"的存在**。当前示例只是其中一种合法解；如果用户要求重新生成，应给出不同的成长经历，导向可能不同的（但同样自洽的）现代立场。

5. **生成规则**（适用于所有来源类型）：若用户提供了成长经历描述 → 采用并融入 `formative_life_history` 块；若用户未提供 → **AI 自行根据用户已提供的其他信息（立场、性格、出身暗示等）推断生成一段 coherent 的成长经历**——不得跳过此块。推断时必须确保 (成长经历 × 性格) 能解释立场形成逻辑，并通过盲测式 coherence test。

**正确做法（信长示例）**：

```yaml
formative_life_history:
  class_origin: "城市小资产阶级家庭（父母为专业工作者 / 小业主）"
  youth_observations:
    - "少年时期目睹家乡制造业在资本垄断与全球化挤压下大量关停，同龄人父母失业、家庭破碎"
    - "在地方公益活动中直接接触被排除在制度外的底层劳动者，目睹贫富差距的制度性根源"
  intellectual_formation: "考入顶尖大学经济学系，系统学习政治经济学、马克思主义与制度经济学；在导师引导下接触'资本主义内改良的局限'相关讨论"
  stance_formation_logic: "把'对权威质疑、判定过时即果断打破'的人格底子放进这段经历：他从小目睹的现象（垄断、贫富差距、产业空心化）被他学到的理论解释为资本主义的结构性矛盾，而非偶然问题；他因此确立最终目标——超越资本主义；至于现阶段怎么走，是他的决策人格在起作用——他判断当今社会条件尚不允许立刻超越资本主义、立刻革命既不现实也注定失败（能用就用、判定此路当下不通就换路），所以现阶段借用议会平台、依靠合法政治手段（议会斗争 + 和平街头）积累力量——这看起来像反叛，但逻辑链条是连贯的，不是为反叛而反叛"
  class_relation: "背叛出身阶级——小资家庭本可安稳过活，但他判断出身阶级所依附的制度终将崩溃"
  alternative_paths_note: "这是同一人格底子的多种 coherent 现代化之一，非唯一解。其他合法解（涵盖不同政治光谱，以示真正的非唯一性）：(1) 出身工人阶级 → 直接的反资本主义；(2) 出身没落资本家家族 → 民族资本 / 反跨国资本；(3) 出身农村 → 农本主义反金融资本；(4) 出身新兴科技创业家庭、亲历管制俘获与寡头垄断 → 自由市场 / 反垄断的右翼制度破坏派（与当前反资本左翼几乎相反，但同样自洽，因为'判定过时即果断打破'可指向打破官僚垄断而非资本垄断）。"
```

**错误做法**：

- ❌ 只写立场（"反资本主义"）不写立场如何形成
- ❌ 成长经历与人格底子矛盾（如让一个"对权威零质疑"的人突然变成反体制革命者，而无任何过渡说明）
- ❌ 成长经历与最终立场逻辑断裂（如少年目睹企业被垄断压垮 → 支持垄断资本）
- ❌ 把当前示例当作"信长现代转化的唯一正确答案"

> 本节落地在 `templates/historical_archetype_conversion.yaml` 的 `modern_fictional_persona.formative_life_history` 块，及 `templates/persona_template.yaml` 的 `human_core.formative_life_history` 块。SPEC §5.3.1 转化方法的第 5 步已包含此要求；本协议 §7 第 8 步与 §7.5 第 10 步是其转化阶段的具体落地。

## 3. 必须删除内容（删除或改写）

> ⚠️ **边界澄清（重要，防止误删）**——「必须删除」针对两类，**不要混淆**：
> 1. **具体事实指纹**：具体事件/战役/政变/丑闻/死亡方式/亲属与家臣名单/政策口号等（即下列各项）。这些会把角色**绑回历史的特定事实**，必须删或改写。**真实政党名称允许保留**（见 §3 修订——政党是公共组织，非个人指纹）。
> 2. **近现代现实政治人物的复刻防护**：见 `modern_political_figure_policy.md` / `recognizability_review.md`，目的是防止冒充/复刻现实在世或近现代政治人物——**这一条只针对近现代现实人物，不针对历史原型**。
>
> **❌ 不属于「必须删除」的**：历史人物的**气质、兴趣审美、行为模式、领导风格**——这些是第 2 节「可保留」的**历史特色**，应转化为现代等价物**保留**（如战国武将→剑道、建安诗人→诗歌、罗马演说家→公开演讲），让转化后的角色仍能看出"来自这个历史人物"。
>
> **一句话**：删除的是「具体事实」，保留的是「气质特色」；**注重非刻板性即可，切勿把历史特色误当指纹删掉**——否则转化后的人物失去来源特色，沦为无味的通用原型。

从历史人物转现代原型时，应**删除或改写**：

- 具体历史事件
- 具体战争
- 具体战役
- 具体政变
- 具体丑闻
- 具体死亡方式
- 具体亲属关系
- 具体家臣 / 部下名单
- ~~具体政党名称~~ **（修订：默认使用虚构政党，由人格与现代条件推演而来。用户可要求替换为真实政党名如 LDP、JCP 等，只要人物本身不可识别为某现实政治人物即可。近现代现实人物提取不得保留其原党派——须重新推演。）**
- 具体政策口号（与人物绑定的独有口号须删；通用政策名可保留）
- 现代现实人物可识别信息
- 会把角色重新绑定到现实历史人物或近现代现实政治人物的**唯一性指纹**

> 检验方法：删除后，把 persona 交给一个不知道来源的知情者（或让 AI 盲测），若仍能识别出原型 → 还有指纹没删干净，回第 3 节继续清。

## 4. 不要矫枉过正

不能把人物抽象得没有味道。

```text
❌ 错误做法：提炼为「一个有领导力的人」。
✅ 正确做法：提炼为「高行动力、低耐心、强控制欲、善用破格人才、对旧权威缺乏敬意、
            危机中倾向先发制人、但容易低估保守反扑的激进改革型政治家」。
```

判断标准：转化后的描述，能否让人**感受到这个人的质感**（他会怎么说话、怎么发火、怎么用人、危机里第一反应是什么），而不只是知道他的“类型标签”。

## 5. 默认现代化背景

历史人物转化为现代原型时，默认设定为：

```yaml
political_system: modern_parliamentary_democracy
reference_model: character's own national parliamentary system
institutional_features:
  - parliament
  - cabinet
  - prime_minister_or_party_leader
  - ruling_party_and_opposition
  - factions
  - committees
  - elections
  - media_pressure
  - support_groups
  - party_discipline
```

注意：

- 制度机制参考**人物所属国家的议会制度**，不强制绑定特定国家——日本历史人物用日本国会机制，中国历史人物用中国人大/政协机制，欧洲人物用欧洲议会制等；
- 可以保留原文化背景、姓名风格、国籍风格（如曹操可保留 China-inspired 虚构议会制国家、凯撒可保留 Roman/Italian-inspired）；
- 但所有角色都必须是**虚构现代政治人物**，不得变成现实政治人物。

## 7. 历史人物转化流程（落实 SPEC §5.3.1 / §17）

> 本 10 步是**转化核心**。完整端到端流程（含前置 source grounding、inferred temperament extraction、后置用户确认 gate）见 `families/political_human/historical_persona_creation_workflow.md` 与 `core/historical_source_grounding.md` / `core/inferred_temperament_extraction.md`。本节不取代、而是被那套工作流包含。

当用户要求将历史人物转化为现代政治家时，执行：

1. **判断是否属于允许历史范围**（地区分界之前；见 `modern_political_figure_policy.md` 第 4 节）；
2. **收集和检索可靠资料**（落盘 `references/research/`，遵守信源纪律）；
3. **区分史料记载、强推断、创作推测**（三级标注）；
4. **识别历史时代的主要矛盾**：该人物当时实际反对/维护的制度结构是什么，为什么；
5. **剥离不可迁移的时代条件**：不要把古代制度、身份秩序、战争结构、宗教权力、古代官职等直接带入现代；
6. **提炼稳定人格结构**（temperament / 欲望 / 恐惧 / 弱点 / 用人 / 对敌 / 对盟友 / 危机反应 / 组织观 / 权力观）；
7. **放入现代议会制社会情况**，分析其面对的制度条件、利益结构、组织惯性与政治约束；
8. **构造一段 coherent 的现代成长经历**（formative_life_history）——出身阶层、少年观察、思想成型路径、（性格 × 经历）→ 立场 的形成逻辑，并明确这是多种 coherent 解中的一个非唯一解（见 §2.4）；
9. **由（人格 × 现代社会情况 × 成长经历）共同推演** 该人格最可能的现代政治立场、支持基础与行动方式；
10. **删除具体历史事件与可识别历史指纹**（第 3 节清单）；
11. **现代化为议会制虚构政治家**（第 5 节背景）并填写 `ideology` 六轴；
12. **进行近现代现实政治人物可识别性审核**（`recognizability_review.md` 全流程，含盲测）；
13. **输出** `persona.yaml`、persona `SKILL.md`、`examples.md`（+ `references/` 留存提炼过程）。

> 重要：若用户选择的任务与 SPEC 或本仓库示例同名（织田信长 / 曹操 / 凯撒），**不得直接套用示例**。必须基于当前资料、用户要求、所选模式重新推算与生成。示例只说明格式与方向。

## 7.5 Historical-to-Modern Conversion Steps（转化产出阶段细化）

在 source grounding（`core/historical_source_grounding.md`）与 inferred temperament extraction（`core/inferred_temperament_extraction.md`）**之后**，按以下顺序把提炼出的人格结构转化为现代议会制虚构政治家（这是 §7 第 6–9 步的字段填充细化）：

1. Identify core human pattern（核心人格模式）。
2. Identify political behavior pattern（政治行为模式）。
3. Identify leadership style（领导风格）。
4. Identify relationship style（关系风格）。
5. Identify crisis behavior（危机行为）。
6. Identify likely modern parliamentary role（最可能的现代议会角色）。
7. Select fictional modern career origin（虚构现代从政前身份）。
8. Select fictional support base（虚构基本盘）。
9. Select ideology axes（意识形态六轴——由人格 × 现代社会情况 × 成长经历共同推演，不从气质直映）。
10. **Construct a coherent modern formative life history**（构造 coherent 现代成长经历：class_origin / youth_observations / intellectual_formation / stance_formation_logic / class_relation / alternative_paths_note——见 §2.4，必须与 personality_archetype 共同解释上一步的 ideology，并通过盲测式的 coherence test）。
11. Select political skills（政治技能）。
12. Select action style（行动风格）.
13. Select private fear and flaw（私下恐惧与弱点）.
14. Select ordinary habits and hobbies（日常习惯与爱好——历史特色的现代等价物，非指纹）.
15. Create modern fictional parliamentary persona（组装现代虚构议会制 persona）.
16. Remove historical fingerprints that should not be directly copied（删除具体历史指纹，见 §3 清单）.
17. Run recognizability and safety review（可识别性与安全审核，含盲测）.
18. Generate complete persona files（生成完整 persona 文件夹，见 generator.md Phase 4）.

> 这 18 步产出的现代 persona，仍须经过 generator.md Phase 5.5 的**用户确认 gate** 才能激活。

## 8. 速查清单（转化完成自检）

- [ ] 第 2 节"可保留"的结构已提炼，且不是干瘪标签（第 4 节）？
- [ ] 没有直接套用历史立场，而是先提炼稳定人格结构，再推演现代立场？
- [ ] 已理解历史时代中的主要矛盾，并将人格结构放入现代社会情况重新推演，而非机械转译？
- [ ] **已生成 `human_core.formative_life_history`**（见 §2.4），且 (成长经历 × 性格) 通过盲测式 coherence test，能解释当前 modern stance 的形成逻辑？
- [ ] **`alternative_paths_note`** 列出了至少 2 个其他 coherent 解，且涵盖不同政治光谱（不仅限于同一立场的变体）？
- [ ] 第 3 节"必须删除"的指纹已全部清除？
- [ ] 盲测：不知来源的知情者/AI 无法识别出原型？
- [ ] 现代化为虚构议会制政治人物（非历史本人穿越复制）？
- [ ] 三级推断已标注（documented/strongly_inferred/speculative，含 formative_life_history 标 speculative）？
- [ ] `meta.safety_status` 为 `safe_conversion`？
