## 3. Documented Facts

史料直接支持、被多个可靠来源重复记载的事实。每条尽量注明来源编号。

- 与足利幕府的关系（多案例之一，体现"质疑→判定阻碍→打破"模式）：1568 拥立足利义昭为将军、进入京都，原可合作；1568 信长拒绝副将军任命、坚持自身独立；1573 因义昭秘密组建"反信长同盟"并多方串通、年初直接发起围攻，信长才在 1573 年 8 月放逐义昭、终结室町幕府（来源 #1, #2, #8, #9）。**注意**：这是他"对权威先质疑、判定阻碍即果断打破"模式的一个具体案例（体现他不是无脑反权威），不应被抽象为"先合作后决裂"的通用范式——火烧延历寺、镇压一向一揆、废公家特权等其他案例都没有"先合作"阶段。
- 刻"天下布武"印（1567 攻占美浓、改稻叶山城为岐阜之后），表明其政治目标是以武力结束乱世、建立新秩序（来源 #1, #2, #3）。
- 促进自由贸易 / 推行"乐市乐座"（rakuichi-rakuza）：废止或松动寺社、座（行会）的垄断特权，扶持新兴商人、搞活流通（来源 #1, #2）。**注意（呼应 SPEC §5.3.1）**：这是 16 世纪商品经济萌芽期、封建框架内的特定历史手段，**不可据此反推**为现代"市场自由派"立场——它只能说明人格底子里的"打破垄断 / 彻底性 / 亲民众倾向"。
- 军事创新与早期火器应用：1554 年村木砦之战（Battle of Muraki Castle）已实施火绳枪连续射击（比传统叙事中的长篠之战早 21 年）；1560 桶狭间以少击多、突袭今川义元本阵；多次以速度与出其不意打破僵局（来源 #1, #2, #6）。**注意**：传统军记叙事中的"长篠三段击/铁炮齐射"是旧日本陆军参谋本部基于军记物语（《甫庵信长记》等）的解读；现代基于《信长公记》一手记载的研究倾向归因于后勤与兵力部署，不应作为信史使用（见 §5）。
- 民政改革：修整道路、撤关所、整顿度量衡，扶持商业流通与交通（来源 #1, #2）。
- 对宗教武装势力（一向一揆 / 本愿寺、延历寺）的镇压极为彻底：火烧延历寺（1571）、长期围攻石山本愿寺（来源 #1, #2）。反映其"对公然抗命/拒绝合作的结构性势力毫不留情"。
- 破格用人：从低出身 / 农民阶层提拔有能力者（最著名即丰臣秀吉），不以门第资历论人；形成以能力与结果为核心的用人体系（来源 #1, #2）。
- 青年时行为放荡不羁、不拘礼节，被时人讥为"大傻瓜"（うつけ者），此事多来源广泛记载（来源 #1, #3）。
- 1582 年本能寺之变（本能寺の変）：被部下明智光秀背叛、围攻，死于本能寺火灾。这是其生命结局，也构成"对背叛极度敏感"的反向史实印证（来源 #1, #2, #3）。
- 开启桃山时代（安土桃山）；关于"打破中世纪、开创近世"的后世史学评价，见 §4（不进入 §3 事实层）。

## 4. Mainstream Historical Interpretations

主流史学解释 / 被多个可靠来源支持的评价。**保留共识，但注明这是"解释"而非"史实"。**

> ⚠️ **本节所有评价均为"后人对结果的解读"，不是信长本人的人格特征**。它们可以保留作为历史评价参照，但**不可作为 `personality_archetype` / `human_core` 等人格字段的描述语**（见 `safety/archetype_conversion_protocol.md` §2.3、`core/inferred_temperament_extraction.md`「核心原则补充」）。转化时，应把这些评价**翻译为可观察的行为倾向与认知模式**——例如"打破中世纪封建秩序"→ "对无法适应时代变化的旧秩序具有较低容忍度"。

- "有缺陷但人性，尽力统一战乱之国"——多个来源给出类似评价：暴烈、冷酷、不择手段，但目标明确且具有开创性（来源 #1, #2）。
- "Demon Daimyō / Great Unifier"——西方史学常用此类对照式表述：既承认其无情（ruthless），又承认其作为统一者的奠基性贡献（来源 #1, #2）。
- 主流定性为**革命性 / 开创性力量**：打破中世纪封建秩序（守护、公家、寺社、座的特权垄断），开创近世中央集权框架，是日本从战国走向统一的关键推手（来源 #1, #2）。**（此项为后人评价；转化时翻译为"对旧秩序低容忍度 / 倾向新建秩序而非改良 / 关注流通与社会结构变化"，不写入人格字段为"革新者"。）**
- 其"乐市乐座 / 撤关所 / 扶持商人"被主流史学解读为**松动封建特权、促进流通与商业**的政策，而非现代意义上的自由市场意识形态（来源 #1, #2）。
- "理想蓝图先行 + 直指根本矛盾"的解读：多数史学解读支持"天下布武"是一个**先行确立的、新建中央集权秩序的政治蓝图**（废公家 / 寺家特权、建中央集权），而非单纯武力征服（来源 #1, #2, #3）。

## 5. Disputed or Uncertain Points

来源之间存在分歧、或证据薄弱之点。列出争议双方观点。

- **"暴君" vs "务实改革者"**：传统叙事（尤其受江户军记物语与后世文学影响）倾向强调其残暴（火烧延历寺、镇压一向一揆的彻底性）；而修正派史学强调其政策务实、有制度建构意图、并非单纯嗜杀（来源 #1, #2）。**本 persona 取"务实革命者"的复合解读**：承认其彻底性与无情，同时承认其有先行理想与制度建设意图。
- **"革命者"标签的强度**：近年修正派研究认为，信长比"革命者"标签所暗示的**更尊重先例、更偏整合**，而非一味破坏（来源 #1 引述的学术讨论）。**本 persona 取"质疑→判定→打破"的复合解读**（见上下文），既保留其判定过时后果断打破的彻底性，也承认他不是无脑反权威。
- **对足利幕府的原始意图（重要修订）**：传统叙事（"傀儡政府从一开始"）认为信长 1568 拥立足利义昭即为日后推翻铺路、一开始即抱持篡权意图。**近年修正派研究**（Wikipedia 引述 rekishikaido、nippon.com 等）认为：信长与义昭起初是合作关系，1568 信长甚至拒绝正式的"副将军"任命；最终的决裂源于义昭秘密组建"反信长同盟"并多方串通、1573 年初直接发起围攻，信长才在 1573 年 8 月放逐之。**本 persona 取修正派解读**（传统说仍存在）：'打破过时旧制度'是合作失败后的行动，而非一开始即抱持推翻意图。这一史源修订是人格提炼中"对旧制度务实态度"的关键依据。
- **长篠之战"三段击/铁炮齐射"战术（重要修订）**：传统叙事称信长在 1575 长篠之战首创"三段击"轮换射击战术。**近年修正派研究**（来源 #1 引述 Atobe Ban 2023 等）发现：该叙事源自旧日本陆军参谋本部对军记物语（Oze Hoan《甫庵信长记》、Tooyama Nobuharu《宗建记》）的解读，**不是**一手史料；基于《信长公记》（太田牛一同时代记载）的现代研究认为长篠之战胜负主要取决于**后勤与兵力部署**，而非特定的轮换射击操典。**本 persona 不将"三段击"作为信史使用**；同时**保留有充分史料支持的 1554 村木砦之战连续射击记载**（比长篠早 21 年），以证明其早期火器采用与战术灵活性。
- **"对低效零容忍"是后世文学解读而非一手记载（重要修订）**：传统印象中信长被描述为"对低效零容忍"、"理性主义者"。**一手记载（Fróis《日本史》）实际描述的脾气是**："disliked long conversations and lengthy preliminaries"（讨厌冗长谈话与繁文缛节）、"meticulous in his instructions"（指令精确细致）、"arrogant but honourable"（傲慢但讲信义）、"extremely cunning in his strategies"（极富计谋）。"对低效零容忍"是 20 世纪理性主义文学解读（坂口安吾《织田信长》等）的产物，**不是一手史料记载的人格特征**。**本 persona 取一手记载**：保留"对繁文缛节/冗长虚文缺乏耐心"作为可观察的行为倾向，删除"对低效零容忍"作为人格定义；同时保留**有充分史料支持的"对公然抗命/拒绝合作者毫不留情"**（火烧延历寺、镇压一向一揆、严惩背叛），这是对"拒绝合作"的无情，而非对"低效"的无情。
- **本能寺之变的原因**：明智光秀为何反叛，史料无定论（怨恨说、野心说、被迫说、阴谋说等多种，均证据不足）。这一点**只用于推断"对背叛敏感 / 高警惕"**（因其确死于部下背叛这一事实），不用于编造光秀的动机。

## 6. Later Myth / Literature / Popular Image

来自小说、演义、戏剧、宣传或后世大众想象的条目。**仅可作风格 / 气质参考，不得进入事实性字段。**

- **"第六天魔王 / 魔王"形象**：信长自号"第六天魔王"的逸事，经江户军记物语（《甫庵信长记》等）与近现代小说、影视、游戏反复渲染，形成"魔王信长"的大众神话。其"魔王"称号的大众形象**远比史实更冷酷、更戏剧化、更反派化**（来源 #1, #5）。
- 影视 / 游戏 / 漫画中的"霸气霸主"刻板形象（如各类大河剧、战国游戏）：夸大其张狂与冷酷，弱化其制度建设、用人智慧与理想主义一面。**仅可作"张狂 / 不羁"风格参考**，不得当作史实。
- "大傻瓜"（うつけ者）青年形象被后世文学戏剧化、夸大其荒诞程度。史实层面该青年放荡记载**真实存在**，但程度被文学放大（来源 #1, #3, #5）。
- 江户军记物语（《甫庵信长记》《太阁记》等）的文学化描写：这些是后世编纂、含大量润色与虚构情节，**不得作为 `documented_behavior` 使用**，只能用于第 7 节的创作边界说明（来源 #5）。

## 7. Creative Inference Boundary

明确：哪些可用于 persona 创作、哪些不得表述为史实。

- **May use for persona**（有史实依据，可进入人格推断）：
  - 高行动力、以速度与出其不意打破僵局（多战役记载）
  - 低耐心（针对冗长虚文与繁文缛节）—— Fróis《日本史》明确记载其 "disliked long conversations and lengthy preliminaries"
  - 对权威与传统秩序的基本态度是"先质疑、不盲从；一旦判定过时或阻碍目标即果断打破"—— 多案例支持：废公家/寺家特权、火烧延历寺、镇压一向一揆、废足利幕府。足利义昭案（1568 拥立为将军、原可合作；1568 拒绝副将军任命；1573 因义昭秘密组建反信长同盟才彻底放逐）是此模式的一个具体表现，体现他不是无脑反权威；但此案不应被抽象为"先合作后决裂"的通用范式（一手文书 + 近年修正派研究；传统说仍存在）
  - 高控制欲、强中央集权倾向（天下布武、废特权）
  - 破格用人、对才能高度敏感、不拘出身（提拔秀吉等）
  - 重情重义 / 对忠诚追随者厚待，同时**对公然抗命/拒绝合作者严惩不贷**（执政记载 + 死于背叛）
  - 青年放荡不羁、不拘礼节、被讥"大傻瓜"（广泛记载）
  - 彻底性 / 对公然抗命的结构性势力毫不留情（火烧延历寺、镇压一向一揆）
  - 理想蓝图先行 / 直指根本矛盾（天下布武蓝图先行）
  - 早期采用火器：1554 村木砦之战已实施连续射击（一手记载，比传统叙事中的长篠之战早 21 年）
- **Must not state as fact**（不得当作史实）：
  - "魔王 / 第六天魔王"的戏剧化形象与由此推出的"嗜杀 / 反派人格"——这是后世文学渲染（来源 #5）
  - 任何"信长内心当时一定在想……"的私密想法编造
  - "乐市乐座 = 信长信奉自由市场资本主义"的现代反推——这是**历史手段 ≠ 人格**的典型陷阱（见 SPEC §5.3.1）
  - **"长篠三段击/铁炮齐射"作为信长的标志性战术**——源自旧日本陆军参谋本部对军记物语的解读，现代研究倾向归因于后勤与兵力部署（见 §3、§5）
  - **"对低效零容忍"作为人格特征**——20 世纪理性主义文学解读（坂口安吾等）的产物，一手记载无此表述；可用"对繁文缛节/冗长虚文缺乏耐心"替代
  - **"信长从一开始即抱持推翻足利幕府的意图"**——传统"傀儡政府从一开始"叙事；近年修正派研究中得到较强支持的解释是先合作、后决裂，传统说仍存在（见 §3、§5）
  - 本能寺之变中明智光秀的"真实动机"——史料无定论
  - 任何"信长因遗传 / 基因 / 天生注定所以如何"的生物决定论表述——本框架**严禁**此类主张

## 8. Inferred Temperamental Pattern

来自 `core/inferred_temperament_extraction.md`。从上述 documented / repeated 行为推断（**非生物决定论**——只从可见史实中反复出现的行动风格推断稳定倾向，不声称先天注定）。

> 术语统一用 `inferred_temperamental_pattern`（推断性气质结构）。它只 inform 现代 persona 的 `human_core`；现代 `political_core.ideology` 仍须由"人格 × 现代社会情况"重新推演（SPEC §5.3.1），**不可从气质直接映射立场**。

```yaml
inferred_temperamental_pattern:
  risk_tolerance:
    value: high
    confidence: high
    evidence_basis:
      - documented_behavior
      - repeated_pattern
    note: >
      多次以少击多、以速度与出其不意打破僵局（1560 桶狭间袭击今川义元本阵、1554 村木砦之战已实施连续射击）；
      常在绝境中押上全部赌命求生。这是跨战役、跨情境反复出现的稳定模式，非孤立事件。
      注意：传统军记叙事中的"长篠三段击"是旧日本陆军参谋本部对军记物语的解读，现代研究
      倾向归因于后勤与兵力部署，不作为本条核心证据（见 §3、§5）。
  patience:
    value: low
    confidence: high
    evidence_basis:
      - repeated_pattern
      - strong_historical_inference
    note: >
      Fróis《日本史》明确记载其 "disliked long conversations and lengthy preliminaries"
      （对冗长谈话与繁文缛节缺乏耐心）；用速度与破格用人推进事务。
      现代人格中表现为"开会常打断议程、直奔要害"。
      注意：这是对'仪式化/冗长虚文'的低耐心，并非现代语境下的'对低效零容忍'
      ——后者是 20 世纪理性主义文学解读（坂口安吾等）的产物，不作为信史（见 §4、§5、§6）。
  emotional_intensity:
    value: high
    confidence: medium
    evidence_basis:
      - repeated_pattern
      - strong_historical_inference
    note: >
      爱憎分明、对旧势力轻蔑彻底、对追随者重情重义；镇压反对派时无情到近乎不留余地。
      情绪反应强烈，但非情绪失控——多与价值判断绑定（背叛 / 公然抗命 / 旧规矩压人）。
  control_need:
    value: high
    confidence: high
    evidence_basis:
      - documented_behavior
      - repeated_pattern
    note: >
      "天下布武"是新建中央集权秩序的蓝图；废公家 / 寺家特权、推行检地与兵农分离——
      系统性地把权力收归中央、按自身蓝图重塑秩序，体现强控制欲。
  dominance_drive:
    value: high
    confidence: high
    evidence_basis:
      - documented_behavior
      - repeated_pattern
    note: >
      对权力格局的态度不是被动适应，而是主动重塑：废公家/寺家特权、废足利幕府、统一进程——
      多案例反复出现。支配欲表现为"重写规则"而非"在规则内上位"。
      注意：这不是"逢权威必反"，而是"对权威与传统秩序先质疑、一旦判定过时或阻碍目标即果断打破"
      ——足利义昭案例只是此模式的一个表现（不是"先合作后决裂"的通用范式）。
  trust_threshold:
    value: medium
    confidence: medium
    evidence_basis:
      - repeated_pattern
      - strong_historical_inference
    note: >
      对"自己人"门槛不低但一旦认定则厚待甚至过度信任；对旧势力与投机者高度警惕。
      信任呈两极分布：圈内全信任、圈外全戒备。
  ambition_level:
    value: high
    confidence: high
    evidence_basis:
      - documented_behavior
      - strong_historical_inference
    note: >
      "天下布武"印、统一进程、新建秩序蓝图——野心指向"重写天下规则"而非"在旧体系内升迁"。
  crisis_response_style:
    value: preemptive
    confidence: high
    evidence_basis:
      - documented_behavior
      - repeated_pattern
    note: >
      危机中倾向先发制人、以攻代守、用速度压倒程序与对手；绝境敢押上一切向死而生。
      非被动防御型，而是"退缩必败、唯有赌命破局"的主动出击型。
      注意："先发制人"适用于威胁/敌意已确立之后——一旦判定对方是阻碍
      （如义昭 1573 围攻、敌方势力的公开对抗），毫不犹豫地主动出击；这与 authority_relation
      的"对权威先质疑"是一致的整体——质疑→判定阻碍→打破/先发制人。
  coalition_style:
    value: flexible_but_dominant
    confidence: medium
    evidence_basis:
      - repeated_pattern
      - strong_historical_inference
    note: >
      结盟灵活（与德川家康长期盟约、与各方时而联合时而翻脸），但盟约须以自身主导为前提；
      一旦盟友成为阻碍则毫不留情。是"主导型结盟者"而非平等合作者。
      与足利义昭的关系即是典型：1568 合作 → 义昭秘密组建反信长同盟 → 1573 决裂放逐。
  talent_recognition_style:
    value: meritocratic
    confidence: high
    evidence_basis:
      - documented_behavior
      - repeated_pattern
    note: >
      破格用人、从低出身提拔能者（秀吉为最著名例子）、以结果与能力取代资历门第。
      这是其最稳定的用人模式，跨情境一致。
  betrayal_sensitivity:
    value: high
    confidence: high
    evidence_basis:
      - documented_behavior
      - strong_historical_inference
    note: >
      死于部下明智光秀背叛（本能寺之变）是反向史实印证；执政记载中对背叛严惩不贷。
      现代人格中表现为对"临阵退缩 / 把忠诚说成交易"极度敏感、wounded_self 易爆发。
  adaptability:
    value: high
    confidence: medium
    evidence_basis:
      - repeated_pattern
      - strong_historical_inference
    note: >
      主动采用新政策（乐市乐座、检地）、新用人体系、早期采用火器
      （1554 村木砦之战已实施连续射击，比传统叙事中的长篠之战早 21 年）——
      乐于打破旧法、按效果而非传统调整手段。但适应是"手段层面灵活、目标层面固执"。
      注意：传统"长篠三段击"叙事的现代研究存疑（见 §3、§5）。
  authority_relation:
    value: questioning_then_decisively_breaking
    confidence: medium
    evidence_basis:
      - documented_behavior
      - strong_historical_inference
    note: >
      对权威与传统秩序的基本态度是"先质疑、不盲从；一旦判定过时或阻碍目标即果断打破"。
      多案例支持：废公家/寺家特权、火烧延历寺（宗教权威）、镇压一向一揆、废足利幕府
      ——不是逢权威必反，而是不因袭、不怀旧，判定过时即重构。
      足利义昭案例（1568 拥立为将军、原可合作；1568 拒绝副将军任命坚持独立；1573 因义昭
      秘密组建反信长同盟才彻底放逐）是此模式的一个具体表现，体现他不是无脑反权威——
      但此案不应被抽象为"先合作后决裂"的通用范式。修正派（见 §5）也认为他比传统叙事
      所暗示的更尊重先例——本 persona 取"质疑→判定→打破"的复合解读。
  empathy_range:
    value: narrow_but_intense
    confidence: medium
    evidence_basis:
      - repeated_pattern
      - disputed_but_useful_for_fiction
    note: >
      对圈内追随者重情重义、近乎过度信任；对旧势力与阻碍者冷酷无情。
      共情范围呈强烈两极：圈内全共情、圈外近乎无共情。部分依赖后世记载，标注争议。
```

> 注：`ideological_rigidity`、`social_flexibility`、`novelty_seeking`、`revenge_tendency` 等维度可由上述条目合理衍生，但为避免冗余并保持证据清晰，此处只列证据最强的核心维度。所有维度均为**从反复行为推断的稳定气质**，**非生物 / 遗传决定**。

## 9. Cold / Sparse-Source Note（若适用）

织田信长**不属于冷源人物**——一手文书、同时代记载（信长公记）、传世书信与多个百科 / 学术综述并存，史料相对充分。

但仍须注意以下证据边界（见第 6、7 节）：

- **后世文学层极厚**："魔王"形象、江户军记物语的戏剧化描写，使大众印象与史实之间存在显著偏差。本 persona 的事实性字段严格基于一手 / 同时代记载与主流史学解释，文学层仅作风格参考。
- **私密心理无史料**：信长的真实内心、情感细节无可靠一手记录。所有 temperament 推断均**从可见行为出发**，不编造私密想法，不声称还原真实内心。
- **现代立场为推演产物**：将信长人格放进现代议会制语境后的政治立场（反资本 / 阶级解放激进革命派）是 SPEC §5.3.1 的推演结果，**非史实**——见 persona.yaml `inference_level.speculative` 与 `context_translation`。

### 证据链总览：资料 → temperament → 转化方向 → 与现有一致

本报告展示了从资料到现有 persona.yaml 的完整可追溯链条：

1. **资料层**（第 2–4 节）：Wikipedia + Britannica + 一手文书 / 同时代记载 → documented facts（**足利义昭 1568 合作→1573 决裂（多案例之一）**、天下布武、乐市乐座、破格用人、1554 村木砦连续射击、死于背叛、开创近世）。
2. **气质层**（第 8 节）：从 documented / repeated 行为 → `inferred_temperamental_pattern`（risk high / patience low（针对繁文缛节）/ control high / dominance high（主动重塑，多案例支持）/ ambition high / crisis preemptive / talent meritocratic / betrayal high / authority questioning_then_decisively_breaking 等），**每条带 evidence_basis**，非生物决定论。
3. **转化方向**（SPEC §5.3.1）：人格底子（理想蓝图先行 + 直指根本矛盾 + '对权威质疑、判定过时即果断打破'的行动倾向 + 亲民众 + 高行动力低耐心）× 现代社会情况（发达资本主义 + 议会制，根本矛盾为资本阶级结构）→ 现代激进改革派 / 反资本阶级剥削。**注意**：乐市乐座是 16 世纪历史手段，**不可反推**"市场自由派"——人格底子才是可迁移物。**"革命性/革新性"作为后世史学评价保留在本报告 §4，不进入人格字段（见 `safety/archetype_conversion_protocol.md` §2.3）。**
4. **史源订正（基于近年修正派研究 + Fróis 一手记载）**：本报告相对早期版本做了四处重要订正——(a) 足利义昭关系从"主动推翻"改为"1568 合作→1573 决裂（近年修正派研究中得到较强支持的解释；传统'傀儡政府从一开始'说仍存在），并明确此案只是'质疑→判定→打破'模式的一个具体表现，**不应当作'先合作后决裂'的通用范式**；其他案例（火烧延历寺、镇压一向一揆、废公家特权）都没有'先合作'阶段；(b) 长篠"三段击/铁炮齐射"从信史改为传统军记叙事（旧日本陆军参谋本部解读，近年研究倾向归因于后勤与兵力部署，见 §3、§5）；(c) "对低效零容忍"从人格特征改为后世文学解读（一手记载无此表述，Fróis 实际描述的是"对繁文缛节/冗长虚文缺乏耐心"）；(d) 人格模式从"先合作后决裂"（过度推广单案例）修正为"对权威质疑、判定过时即果断打破"（多案例归纳）。
5. **与现有 persona.yaml 一致**：现有 persona.yaml 的核心方向（对权威质疑、判定过时即果断打破 / 理想蓝图先行 / 高行动力 / 低耐心（针对繁文缛节）/ 反垄断→反资本 / 亲民众）与上述订正后的史料支持**方向一致**，由 Wikipedia 现代研究 + Fróis 一手记载支持。本报告补齐的就是这条"方法论可复现"的证据链。
